Project Narrative

What is Ibis Equity?

Ibis Equity Consulting, LLC is an AI/ML advisory and engineering firm whose mission is captured in its tagline: "Where Intelligence Meets Equity." The firm specializes in Machine Learning, Generative AI, Data Science, Cloud Computing, and Agentic AI — fields that are reshaping every major industry sector. Ibis Equity's thesis is that advanced AI capabilities should not be the exclusive province of large enterprises with deep technical teams; they should be accessible, explainable, and ethically deployed across organizations of all sizes.

What the Site Does

The site is a content-rich, AI-powered consulting portal. It opens with an animated splash screen, transitions to a home page that houses an embedded RAG chatbot (powered by AWS OpenSearch Serverless and Amazon Bedrock / Claude), and then branches into a library of deep-content destination pages — one per technology discipline or industry vertical. Each destination page delivers long-form, consultant-grade narrative on how AI and cloud technologies apply to that domain, complete with comparison matrices, architecture cards, and step-by-step breakdowns. A contact form lets prospective clients submit engagement requests directly from the site.

The RAG Chatbot

The centrepiece of the home page is an AWS-native Retrieval-Augmented Generation (RAG) assistant. When a visitor asks a question, the Angular frontend sends the query to the FastAPI backend, which retrieves semantically similar document chunks from Amazon OpenSearch Serverless using Amazon Titan Embeddings, then passes those chunks along with the question to Amazon Bedrock (default model: amazon.nova-micro-v1:0; configurable to Anthropic Claude). The grounded answer, source citations, and an optional Amazon Polly text-to-speech audio clip are returned to the user. Knowledge base document ingestion — including diagram-caption extraction from PDFs via Claude — is handled by a companion Streamlit utility (ingest_diagram_captions.py).

Contact & Lead Capture

A contact form collects prospective client details (name, organization, role, and engagement request). The FastAPI backend stores each submission in Amazon DynamoDB, sends a formatted notification email via Amazon SES, and dispatches an SMS alert via Amazon SNS — giving the Ibis Equity team immediate, multi-channel awareness of every inbound request.

Developer Workflow

The repo is designed for a tight inner-loop experience. Running npm run start:full launches both the Angular dev server (port 4202) and the Uvicorn FastAPI server (port 8010) concurrently. A proxy configuration forwards /api/* requests from the frontend to the backend so no CORS configuration is needed during local development. For AWS-authenticated sessions, npm run start:full:aws exports live credentials from the configured AWS CLI profile before starting the servers.

Architecture Summary

Angular 21 SPA proxies REST calls to a FastAPI backend. The backend implements a RAG pipeline: user questions go to Amazon Bedrock (Nova / Claude models), with document embeddings stored in Amazon OpenSearch Serverless. Contact form submissions are persisted in DynamoDB and trigger SES email + SNS SMS notifications. Amazon Polly provides optional text-to-speech audio on RAG responses.
